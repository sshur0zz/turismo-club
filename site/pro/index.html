Le vrai espace équipe (connexion du personnel, gestion des réservations) arrive bientôt. En attendant, les demandes envoyées depuis le site se consultent dans Supabase.

  1. Voir les nouvelles demandes : ouvrez le tableau de bord Supabase, puis la table quote_requests. Chaque ligne est une demande ; les plus récentes ont la date created_at la plus proche.
  2. Lire la demande : nom, e-mail, téléphone, offre (offer_slug), date, nombre de personnes, langue préférée et message.
  3. Changer le statut : double-cliquez sur la case status et choisissez in_progress (en cours), sent (proposition envoyée), won (confirmée) ou lost (perdue), puis enregistrez.
